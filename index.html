PowerShell_Export-hMailServerData

Every mailbox definition, in any format you need

Exports hMailServer domains, accounts, aliases and distribution lists through the COM API to CSV, JSON, Markdown, JS, PHP and XML for migrations, audits and dashboards.

What it does

  • Reads live configuration through the COM API
  • Six output formats from one run
  • Structured logging and debug mode
